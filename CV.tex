\section{Entrepreneurship}
\sectionrule

\datecolor{2024--2025}\par
\runsubsection{Co-Founder --- \href{https://github.com/unifyai/ivy}{Ivy}}\par
Created Ivy with two former colleagues, as a spin-off from our previous company (Unify), with the blessing of their CEO.
We adapted the existing framework to allow any ML models or code to be converted between frameworks such
as PyTorch and JAX.
The design of the transpiler involved advanced Python programming, including AST manipulation and function tracing.
To create the customer-facing interface, I did significant backend development and DevOps using cloud infrastructure (GCP).

\vspace{2pt}
After interviewing with Y Combinator and talking to potential customers, we failed to prove commercial viability, so we
ended Ivy as a venture and open-sourced the project - which is available on \href{https://github.com/unifyai/ivy}{\textit{GitHub}}
and \href{https://pypi.org/project/ivy/}{\textit{PyPI}}.
